# S1: Astro kostur, zajednički tipovi, dev protiv mocka, mjerenje SSR-a, design brief

Polazni commit: (upisuje S0). Korijen: `npm test` 97 testova. Odluke od **100**.

Prvi dodir s kodom. Ništa od ovoga ne ide na mrežu ni na Cloudflare.

Paket:

1. **Astro projekt u `web/`.** `npm create astro@latest` (prazan predložak, TypeScript
   strict) pa `@astrojs/cloudflare` i `@astrojs/react`. Vlastiti `package.json` i
   `package-lock.json` u `web/`; korijenski se ne mijenja. `output: "server"` (odluka 2).
   Verzije zapiši u odluku 100. Ako trenutni `@astrojs/cloudflare` traži noviji
   `wrangler` ili `compatibility_date` nego korijen (`wrangler ^3.95`, `2024-11-01`),
   `web/` smije imati svoj; zapiši kao odluku.
2. **`web/wrangler.jsonc`.** Ime `domovina-ulaznice-web-staging` (env `staging`) i
   `domovina-ulaznice-web` (vrh, ne deploya se). Bez D1, KV, ruta i tajni. Jedini var
   `API_BASE_URL`. Komentar na vrhu kao u korijenskom `wrangler.jsonc`: zašto nema baze.
3. **Zajednički tipovi.** Premjesti sučelja (`TierView`, `EventDetails`, `EventView`,
   `TicketView`, `OrderView`, …) iz `src/lib/api.ts` u `shared/api-tipovi.ts`;
   `src/lib/api.ts` ih uvozi i re-exporta. Korijenski `npm run build` i `npm test`
   moraju ostati zeleni. `web/` ih uvozi relativnom putanjom ili aliasom (zapiši koju).
4. **API klijent u `web/src/lib/api.ts`.** Na serveru (SSR) `fetch(new URL(path, API_BASE_URL))`;
   u pregledniku relativni `/api/...`. Isti `ApiError(code, status)` kao u SPA-u.
5. **Dev protiv mocka.** U `web/astro.config.mjs` Vite proxy `/api` → `http://localhost:8797`.
   Skripta `npm --prefix web run dev:mock` koja pokrene
   `PUBLIC_BASE_URL=http://localhost:4321 node ../mobile/mock-api.mjs` i `astro dev`
   (dva procesa, npr. `concurrently` ili mala node skripta). Provjeri da mockov
   „Plati” vraća na `http://localhost:4321/ulaznice/<id>?placeno=1`.
6. **Jedna prava stranica kao mjerenje:** `web/src/pages/dogadjaj/[slug].astro` s
   `<title>` i `<meta property="og:title">` iz `GET /api/dogadjaj/:slug`, bez dizajna.
   Izmjeri u `wrangler dev` (ne samo `astro dev`):
   `curl -s localhost:<port>/dogadjaj/prilika-za-susret-2027 | grep -E '<title>|og:title'`.
   Zapiši rezultat, veličinu Worker bundlea i vrijeme odgovora u
   `web/docs/research/YYYY-MM-DD-ssr-na-workersu.md`. **Ako SSR na Workersu ne radi,
   stani**, zapiši zašto i upiši pitanje na vrh `S2.md` (plan se mijenja prije dizajna).
7. **`npm --prefix web run check`** = `astro check` + `node --test` (barem jedan test za
   API klijent, npr. da se `ApiError` gradi iz `{error: "tier_sold_out"}` sa statusom 409)
   + `astro build`.
8. **`web/docs/design-brief.md`** za Claude Design. Sadrži:
   - ekrane: popis događaja, događaj, kupnja, narudžba (stanja pending, paid, expired,
     refunded, failed), uvjeti/privatnost, 404; mobitel 390 px i desktop 1280 px;
   - podatke koje ekran prima (polja iz `shared/api-tipovi.ts`, primjer iz mocka);
   - stanja tiera: dostupno, rasprodano, prodaja nije počela, završila, `kupovno: false`,
     imenska ulaznica (polje za ime po komadu);
   - poruke grešaka iz `worker/api.ts` (popis kodova) koje UI mora prikazati;
   - `brand.accent_color` po događaju, hrvatski jezik, pristupačnost (kontrast AA);
   - što **ne** dizajnirati: organizator, skener.
   Ivan ga lijepi u Claude Design.
